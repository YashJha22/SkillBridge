# SkillBridge

SkillBridge is an Android application built to help students grow in one place. Instead of switching between different apps to learn new skills, find opportunities, and understand investing, SkillBridge aims to bring everything together in a single platform.

## Why SkillBridge?

As students, we often use one app for learning, another for internships or freelancing, and a different one for finance. Managing all of these separately can be frustrating.

SkillBridge is my attempt to simplify that experience by creating one app where students can learn, earn, and invest.

## Planned Features

- 📚 Learn new skills through structured content.
- 💼 Discover internships, freelance work, and real-world projects.
- 📈 Learn the basics of investing and personal finance.

## Built With

- Kotlin
- Jetpack Compose
- Material 3
- Android Studio
